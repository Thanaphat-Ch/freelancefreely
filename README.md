# 🚀 freelancefreely 
> A full-stack web application that connects freelancers with clients, enabling job posting, job searching, secure communication, and efficient project management.

---

## ✨ Features
*   🔐 Secure authentication with Passport.js and JWT
*   💼 Browse and apply for freelance jobs
*   📝 Post and manage job listings
*   💬 Real-time chat powered by Firebase Firestore
*   🖼️ Image upload and storage with Cloudinary
*   📱 Responsive design for desktop, tablet, and mobile devices

## 🛠️ Tech Stack
*   **Frontend:** React, vite, Tailwind CSS
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB, Firebase Firestore (Real-time Chat)
*   **Authentication** Passport.js, JWT
*   **Cloud Storage** Cloudinary
